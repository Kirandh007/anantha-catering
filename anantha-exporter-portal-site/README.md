# Anantha Exporter Portal

Static website package for Anantha Catering Services.

## Deploy

Upload this complete folder to a static hosting service such as Cloudflare Pages, GitHub Pages, Netlify, or Vercel. The entry point is `index.html` and every image asset in this folder must be uploaded with it.

## Contents

- ACS logo
- GST registration certificate
- Hero image and product catalogue images
- Interactive RFQ cart, dashboard and commercial quotation prototype
